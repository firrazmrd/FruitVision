Foto asli (opsional) untuk FruitVision
======================================
Aplikasi berjalan penuh tanpa foto (memakai ilustrasi vektor). Untuk memakai fotografi sendiri:
1. Letakkan berkas di folder ini, mis. hero-fruit.jpg (rasio 1:1, minimal 900 px, <= 300 KB lebih baik).
2. Daftarkan di manifest.json, contoh:
   { "hero-fruit.jpg": { "alt": "Apel segar di kebun", "credit": "Nama fotografer / sumber, lisensi" } }
Hanya foto dengan lisensi yang Anda punya haknya (milik sendiri, atau CC0/Unsplash/Pexels dengan atribusi yang sesuai).
Slot yang didukung saat ini: hero-fruit.jpg (pelat pemindai di halaman utama).
